PERFORMANCE
-----------
  This pack uses a single 512px texture atlas shared across all
  348 prefabs. This means:

  - Minimal draw calls when using static batching
  - Tiny 2.3MB footprint — smaller than a single photo
  - Runs on low end PC, mobile, and WebGL without issues
  - No PBR, no normal maps, no unnecessary overhead
  - Drop hundreds of props in your scene with zero performance cost


HOW TO USE
----------
  1. Import the package into your Unity project
  2. Open the Demo Scene to browse all props in context
  3. Drag any prefab from the Prefabs folder into your scene
  4. All props share one material — perfect for static batching
  5. Enable static batching on props for maximum performance:
     Inspector → Static checkbox ✅
